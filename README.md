# Klub Members

Clube de membros white-label para e-commerces — gamificação (Rewards), lançamentos exclusivos (Drops) e comunidade (Community) para aumentar LTV e reduzir CAC.

- Visão de produto: [docs/PRD.md](docs/PRD.md)
- Roadmap de desenvolvimento: [docs/ROADMAP.md](docs/ROADMAP.md)

## Stack

Next.js (App Router) + TypeScript + Tailwind + Neon (Postgres) + Drizzle ORM.

## Rodando localmente

```bash
npm install
npm run dev
```
